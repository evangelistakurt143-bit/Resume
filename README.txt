KURT EVANGELISTA — RESUME & PORTFOLIO WEBSITE

FILES
- index.html: website content and section structure
- styles.css: colors, typography, layout, and responsive styling
- script.js: mobile navigation, print button, and small interactions

OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Choose File > Open Folder.
4. Select the extracted kurt_portfolio_site folder.
5. Open index.html.
6. Optional: install the Live Server extension, right-click index.html,
   and choose "Open with Live Server".

BEFORE PUBLISHING
1. Replace ADD-YOUR-EMAIL@example.com with your real professional email.
2. Replace the LinkedIn and GitHub placeholder links in index.html.
3. Replace the KE profile-photo placeholder with your own professional photo.
4. Review every statement and update it to reflect your current skills accurately.
5. Build the sample portfolio tasks before describing them as completed work.
6. Add only courses/certificates you have actually completed.

CUSTOMIZING
- Edit text and section content in index.html.
- Edit colors, fonts, spacing, and layout in styles.css.
- Edit mobile menu and print behavior in script.js.

The design is an original implementation inspired by the reference portfolio's
editorial layout and section flow. It does not copy the original person's text,
identity, projects, or assets.
